Siteation_DebugBar

Build tracker for siteation/magento2-debugbar. A modern debug bar for Magento 2.4.9 on Hyvä and Nebula, modelled on New Debug Bar: stored request profiles, ranked findings, an Alpine viewer, and a read only MCP server.
